> Read https://ohmyho.st/llms.txt and https://ohmyho.st/skills/ohmyhost-get-started/SKILL.md. Connect this agent to ohmyho.st and deploy this GitHub project using only the capabilities it needs. Follow the deployment Skill, keep my existing project decisions and verify the app.

Your agent tells you what it needs, gives you one sign-in link, reuses your workspace and inspects the selected app before creating anything. Signing up is open; you only need a browser once.

## Start with what your app needs

A public Vite app can start with hosting alone. Add Postgres, runtime secrets, a custom domain or transactional email when the application needs them. Keep your application's own authentication provider.

## Your first result

The agent follows the accepted deployment and verifies the real application. Dev is protected by default: ask your agent for the reusable Dev share link, or choose public Dev when the project is created. Publish to Prod after you are ready.

- [First deployment](/quickstart): the complete GitHub workflow.
- [Connect MCP](/agents/mcp): setup for your agent.
- [CLI](/cli): install and run the commands yourself.
- [API](/api): use your account token from another tool.

## Come back with a question

“Which project used the most credits?” “Is my domain ready?” “Export my database.” Your agent reads the saved [project context](/project-context) and uses the same account access as the [portal](https://app.ohmyho.st/).
