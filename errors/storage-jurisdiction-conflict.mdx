---
title: "Storage jurisdiction conflict"
description: "What the `storage_jurisdiction_conflict` error means and what to do next."
---

The API, CLI and MCP return `storage_jurisdiction_conflict` with HTTP 409. Retrying the same request unchanged does not help.

## What to do

Set storage.jurisdiction in ohmyhost.yaml to the project's hosting region shown by project status, then plan again.

Keep the `request_id` from the error when you [report the problem](/feedback).
