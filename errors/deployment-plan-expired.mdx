---
title: "Deployment plan expired"
description: "What the `deployment_plan_expired` error means and what to do next."
---

The API, CLI and MCP return `deployment_plan_expired` with HTTP 409. Repeating the same request unchanged does not help.

## What to do

Run 'ohmyhost plan' again, then deploy the new plan.

If the steps above do not resolve it, [report it](/feedback) with the `request_id` from the error.
