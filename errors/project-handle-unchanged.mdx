---
title: "Project handle unchanged"
description: "What the `project_handle_unchanged` error means and what to do next."
---

The API, CLI and MCP return `project_handle_unchanged` with HTTP 409. Retrying the same request unchanged does not help.

## What to do

The project already answers on this address; no rename is needed.

Keep the `request_id` from the error when you [report the problem](/feedback).
