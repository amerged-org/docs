The API, CLI and MCP return `project_handle_unchanged` with HTTP 409. Repeating the same request unchanged does not help.

## What to do

The project already answers on this address; no rename is needed.

If the steps above do not resolve it, [report it](/feedback) with the `request_id` from the error.
