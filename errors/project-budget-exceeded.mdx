---
title: "Project budget exceeded"
description: "What the `project_budget_exceeded` error means and what to do next."
---

The API, CLI and MCP return `project_budget_exceeded` with HTTP 402. Retrying the same request unchanged does not help.

## What to do

Raise the project's stop budget or select continue, then retry the same request.

Keep the `request_id` from the error when you [report the problem](/feedback).
