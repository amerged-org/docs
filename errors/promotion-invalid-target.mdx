---
title: "Promotion invalid target"
description: "What the `promotion_invalid_target` error means and what to do next."
---

The API, CLI and MCP return `promotion_invalid_target` with HTTP 409. Repeating the same request unchanged does not help.

## What to do

Select the current succeeded dev deployment and target prod.

If the steps above do not resolve it, [report it](/feedback) with the `request_id` from the error.
