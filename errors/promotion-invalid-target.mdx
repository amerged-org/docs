---
title: "Promotion invalid target"
description: "What the `promotion_invalid_target` error means and what to do next."
---

The API, CLI and MCP return `promotion_invalid_target` with HTTP 409. Retrying the same request unchanged does not help.

## What to do

Select the current succeeded dev deployment and target prod.

Keep the `request_id` from the error when you [report the problem](/feedback).
