---
title: "Mail domain conflict"
description: "What the `mail_domain_conflict` error means and what to do next."
---

The API, CLI and MCP return `mail_domain_conflict` with HTTP 409. Retrying the same request unchanged does not help.

## What to do

Read and use the sender domain already configured for this project.

Keep the `request_id` from the error when you [report the problem](/feedback).
