---
title: "Promotion target stale"
description: "What the `promotion_target_stale` error means and what to do next."
---

The API, CLI and MCP return `promotion_target_stale` with HTTP 409. Repeating the same request unchanged does not help.

## What to do

Read the current prod status, then plan promotion again.

If the steps above do not resolve it, [report it](/feedback) with the `request_id` from the error.
