---
title: "Database access limit"
description: "What the `database_access_limit` error means and what to do next."
---

The API, CLI and MCP return `database_access_limit` with HTTP 409. Retrying the same request unchanged does not help.

## What to do

List the project's database credentials and revoke one you no longer need, then request access again.

Keep the `request_id` from the error when you [report the problem](/feedback).
