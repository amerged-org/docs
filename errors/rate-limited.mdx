---
title: "Rate limited"
description: "What the `rate_limited` error means and what to do next."
---

The API, CLI and MCP return `rate_limited` with HTTP 429. Repeating the same request, with the same idempotency key, after a wait can succeed.

## What to do

Too many requests. Wait retry_after_seconds, or 60 seconds when none is shown, then repeat the same request with the same idempotency key. SQL exports allow one request per project per rolling 24 hours: poll the export already requested with 'ohmyhost export get EXPORT_ID --project ULID --json' instead of creating another.

If the steps above do not resolve it, [report it](/feedback) with the `request_id` from the error.
