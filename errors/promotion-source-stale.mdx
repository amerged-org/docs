---
title: "Promotion source stale"
description: "What the `promotion_source_stale` error means and what to do next."
---

The API, CLI and MCP return `promotion_source_stale` with HTTP 409. Repeating the same request unchanged does not help.

## What to do

Read the current dev deployment, then plan promotion again.

If the steps above do not resolve it, [report it](/feedback) with the `request_id` from the error.
