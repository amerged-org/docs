---
title: "Mail domain required"
description: "What the `mail_domain_required` error means and what to do next."
---

The API, CLI and MCP return `mail_domain_required` with HTTP 409. Retrying the same request unchanged does not help.

## What to do

Run 'ohmyhost mail domain set' for this project, then plan again.

Keep the `request_id` from the error when you [report the problem](/feedback).
