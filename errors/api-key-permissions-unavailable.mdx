---
title: "Api key permissions unavailable"
description: "What the `api_key_permissions_unavailable` error means and what to do next."
---

The API, CLI and MCP return `api_key_permissions_unavailable` with HTTP 503. Retrying the same request unchanged does not help.

## What to do

Report the platform user-key permission configuration through feedback. Repeated login or creation will not fix it.

Keep the `request_id` from the error when you [report the problem](/feedback).
