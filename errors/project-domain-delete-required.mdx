---
title: "Project domain delete required"
description: "What the `project_domain_delete_required` error means and what to do next."
---

The API, CLI and MCP return `project_domain_delete_required` with HTTP 409. Repeating the same request unchanged does not help.

## What to do

This project still has a live or pending custom-domain connection. Read 'ohmyhost domain paid status --project ULID --json', remove that connection with 'ohmyhost domain paid delete --project ULID --hostname HOST --yes --json', then create a fresh project deletion plan. Repeating while it remains connected cannot work.

If the steps above do not resolve it, [report it](/feedback) with the `request_id` from the error.
