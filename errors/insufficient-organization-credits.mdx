---
title: "Insufficient organization credits"
description: "What the `insufficient_organization_credits` error means and what to do next."
---

The API, CLI and MCP return `insufficient_organization_credits` with HTTP 402. Retrying the same request unchanged does not help.

## What to do

Add organization credits or wait for reservations to settle, then retry the same request.

Keep the `request_id` from the error when you [report the problem](/feedback).
