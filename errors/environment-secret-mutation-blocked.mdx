---
title: "Environment secret mutation blocked"
description: "What the `environment_secret_mutation_blocked` error means and what to do next."
---

The API, CLI and MCP return `environment_secret_mutation_blocked` with HTTP 409. Retrying the same request with backoff can succeed.

## What to do

Wait for the active deployment or rollback to finish, then retry unchanged.

Keep the `request_id` from the error when you [report the problem](/feedback).
