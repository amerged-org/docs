---
title: "Environment secret mutation blocked"
description: "What the `environment_secret_mutation_blocked` error means and what to do next."
---

The API, CLI and MCP return `environment_secret_mutation_blocked` with HTTP 409. Repeating the same request, with the same idempotency key, after a wait can succeed.

## What to do

Wait for the active deployment or rollback to finish, then retry unchanged.

If the steps above do not resolve it, [report it](/feedback) with the `request_id` from the error.
