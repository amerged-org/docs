---
title: "Confirmation expired"
description: "What the `confirmation_expired` error means and what to do next."
---

The API, CLI and MCP return `confirmation_expired` with HTTP 409. Repeating the same request unchanged does not help.

## What to do

Plan the destructive action again before confirming it.

If the steps above do not resolve it, [report it](/feedback) with the `request_id` from the error.
