---
title: "Payload too large"
description: "What the `payload_too_large` error means and what to do next."
---

The API, CLI and MCP return `payload_too_large` with HTTP 413. Repeating the same request unchanged does not help.

## What to do

Reduce the request size.

If the steps above do not resolve it, [report it](/feedback) with the `request_id` from the error.
