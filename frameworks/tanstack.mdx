title: "Host a TanStack application"
description: "Distinguish TanStack Start from Router and Query in a Vite app."
---

Use the [Vite guide](/frameworks/vite) when the project uses TanStack Router or Query in a Vite frontend. For TanStack Start, retain native server routes, loaders and server functions.

Run `ohmyhost init --dry-run --json`. The result identifies the actual framework/runtime, package manager and required capabilities. Resolve concrete unsupported behavior; do not choose a runtime or authentication system from a package name alone.

Scheduled work is declared as `functions.crons` and runs `scheduled` from the default export of `src/ohmyhost/worker.ts`, a module the platform bundles outside the TanStack Start build; see [Functions and cron](/functions).

## Deploy and verify

Follow [the GitHub deployment workflow](/quickstart). Set server credentials through [runtime secrets](/secrets), and configure the exact application-auth callback/logout URLs.

After the build, verify rendered pages, client navigation, loaders, server functions and the requested data writes. For isolated environments, verify existing Prod records after promotion rather than copying Dev data across.
