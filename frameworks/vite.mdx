---
title: "Host a Vite or React app"
description: "Deploy a public frontend or a Vite app with its supported server companion."
---

A public Vite application can deploy with hosting alone. Run `ohmyhost init --dry-run --json`, keep a pinned package manager and its matching lockfile, and follow the returned requirements.

React, TanStack Router and TanStack Query can be part of a Vite frontend. Those packages do not by themselves turn it into TanStack Start.

## When the app needs a server

Follow the actual same-origin API companion contract returned by inspection. Implement the routes the browser calls and configure private [runtime secrets](/secrets) for that server. `VITE_` variables are public build-time values; they must not contain private credentials.

Retain the customer's selected auth provider. A frontend-only application must use the provider's public-client flow; server-only SDKs belong in a supported server component.

## Verify the deployment

Test client navigation and a direct reload of a nested route. Then test any actual server/auth/data feature. Use the [portable-app Skill](https://ohmyho.st/skills/ohmyhost-build-portable-app/SKILL.md) to resolve supported companion requirements and the [deployment workflow](/quickstart) to publish.
