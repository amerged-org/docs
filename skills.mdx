---
title: "Agent Skills"
---

Skills teach your agent how to complete a specific task with ohmyho.st. Install the ones you need:

```
npx skills add amerged/docs -s ohmyhost-deploy-github
```

Replace the Skill name to install another. Current MCP releases also expose these instructions as readable resources.

- [ohmyhost-build-portable-app](https://ohmyho.st/skills/ohmyhost-build-portable-app/SKILL.md) — Build or adapt a TypeScript Vite, TanStack Start, or Next.js application for the ohmyho.st runtime. Use for application feature work and source preparation; use the migration Skill for a customer-requested Supabase conversion.
- [ohmyhost-deploy-github](https://ohmyho.st/skills/ohmyhost-deploy-github/SKILL.md) — Deploy a GitHub application to ohmyho.st and verify or promote its release. Use for first deployment or a new commit; use the troubleshooting skill for an already stuck operation.
- [ohmyhost-domains-and-mail](https://ohmyho.st/skills/ohmyhost-domains-and-mail/SKILL.md) — Connect a custom domain or transactional email to ohmyho.st, provide manual DNS records, and check DNS, HTTPS or DKIM readiness. Use when a hostname or sender is being configured or is pending.
- [ohmyhost-export-database](https://ohmyho.st/skills/ohmyhost-export-database/SKILL.md) — Request and download an on-demand password-encrypted SQL ZIP from ohmyho.st. Use for a customer database backup or export; does not restore or overwrite another database.
- [ohmyhost-get-started](https://ohmyho.st/skills/ohmyhost-get-started/SKILL.md) — Connect a customer agent to ohmyho.st, complete invitation signup and select an organization before the first GitHub deployment. Use for first-time installation or login; use the deployment Skill once access is ready.
- [ohmyhost-manage-database](https://ohmyho.st/skills/ohmyhost-manage-database/SKILL.md) — Inspect or change ohmyho.st database compute and prepare safe Dev-to-Prod schema migrations. Use for database sizing, idle costs, shared versus isolated data, or promotion migrations.
- [ohmyhost-migrate-supabase-postgres](https://ohmyho.st/skills/ohmyhost-migrate-supabase-postgres/SKILL.md) — Migrate customer-selected Supabase capabilities in a TypeScript application to portable PostgreSQL and the ohmyho.st runtime. Use when real Supabase database, Auth, Storage, Functions or Realtime usage needs conversion; not merely because an SDK is installed.
- [ohmyhost-troubleshoot-deployment](https://ohmyho.st/skills/ohmyhost-troubleshoot-deployment/SKILL.md) — Diagnose a failed or stalled ohmyho.st deployment, resume an eligible operation, or report a product bug or feature request. Use for queued, publishing, mail-wait and build errors; not for starting a new release.
- [ohmyhost-usage-and-budgets](https://ohmyho.st/skills/ohmyhost-usage-and-budgets/SKILL.md) — Explain ohmyho.st measured usage, remaining credits and project spending limits. Use for cost reports, low-credit questions, budget changes or customer-requested billing actions.
