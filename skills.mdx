Install the entry Skill from the public repository:

```sh
npx skills add amerged/docs -s ohmyhost-get-started
```

Use another name from the catalogue for a specific task. The CLI packages and Skills do not require access to the private platform repository. Current product MCP servers also expose these instructions through their resources.

Skills preserve the customer's selected application, auth provider and Dev/Prod decision. They call the public CLI/MCP contract, inspect actual status and report missing behavior through feedback. Installation alone does not authenticate the agent.
