Load `OHMYHOST_TOKEN` from a private environment file or your secret store, then create an explicit client:

```ts
import { createClient, listProjects } from '@ohmyhost/sdk-ts';

const token = process.env.OHMYHOST_TOKEN;
if (!token) throw new Error('OHMYHOST_TOKEN is required');
const client = createClient({
  baseUrl: 'https://app.ohmyho.st',
  headers: { Authorization: `Bearer ${token}` },
});
const response = await listProjects({ client });
console.log(response.data);
```

Use the generated operation's parameter types for path, query, headers and body. Keep this token outside browser bundles and application source. A project or user ID identifies a resource but does not authorize access.

For an asynchronous mutation, retain its idempotency key and observe the returned operation. Handle typed API errors rather than silently returning success. [API contract](/api) · [Authentication](/login-tokens) · [Deployment workflow](/quickstart).
