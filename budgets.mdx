---
title: "Project spending limits"
description: "Set a UTC-month credit limit and choose Continue or Stop."
---

Read the current budget before changing it:

```sh
ohmyhost budget get --project "$PROJECT_ID" --json
```

Set a limit, or explicitly remove it:

```sh
ohmyhost budget set --project "$PROJECT_ID" --credits 1000 --mode stop --idempotency-key "$BUDGET_REQUEST_KEY" --json
ohmyhost budget set --project "$PROJECT_ID" --credits none --idempotency-key "$UNLIMITED_REQUEST_KEY" --json
```

These are alternatives; run the one matching your decision. Use `--mode continue` when the budget should remain advisory. Each intentional change gets its own retained key; repeat an uncertain request with the original arguments/key.

The limit uses a UTC calendar month. **Stop** applies the service's budget admission policy; **Continue** allows work to continue after the threshold. Existing work and delayed measurements may settle later, so the setting is not a promise that all final costs stop at an exact instant.

## Use the portal

Open [Usage](https://app.ohmyho.st/usage), select the project limit and behavior, save, then verify the returned value. The portal uses the same endpoint and authorization as CLI/MCP.
